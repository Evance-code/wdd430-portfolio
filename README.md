# WDD 430 Portfolio

A personal portfolio site built with Next.js, TypeScript, and Tailwind CSS as part of WDD 430: Web Full-Stack Development at BYU-Idaho.

## Live Site

🔗 [https://wdd430-portfolio-mauve.vercel.app](https://wdd430-portfolio-mauve.vercel.app)

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Deployed on Vercel
